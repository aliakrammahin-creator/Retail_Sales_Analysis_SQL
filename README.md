                                           # Retail Sales Analysis Using SQL

## Project Overview

This project focuses on analyzing retail sales data using **MySQL** to uncover meaningful business insights. The dataset contains transactional sales records, including customer information, product categories, sales amounts, quantities purchased, and transaction dates.

The objective of this project was to perform data cleaning, explore the dataset, and answer real-world business questions using SQL techniques such as aggregations, Common Table Expressions (CTEs), and window functions.

---

## Dataset

The dataset includes the following information:

- Sales Transactions
- Customer Details
- Product Categories
- Sales Amount
- Quantity Purchased
- Transaction Date & Time

---

## Data Cleaning

The following data cleaning steps were performed before analysis:

- Checked for missing values in all key columns.
- Removed records containing NULL values to improve data quality.
- Disabled MySQL Safe Update Mode to allow deletion of invalid records.
- Verified the cleaned dataset before performing analysis.

---

## Exploratory Data Analysis

Initial exploration included:

- Counting total sales transactions
- Identifying unique product categories
- Counting unique customers
- Understanding the overall structure of the dataset

---

## Business Questions Answered

This project answers the following business questions:

1. Retrieve all sales made on a specific date.
2. Find clothing purchases with a quantity greater than or equal to 4 during November 2022.
3. Calculate total sales and total orders for each product category.
4. Determine the average age of customers who purchased Beauty products.
5. Identify transactions where total sales exceeded 1000.
6. Count transactions by gender within each product category.
7. Determine the best-selling month in each year using Window Functions.
8. Identify the Top 5 customers based on total sales.
9. Count the number of unique customers for each product category.
10. Categorize transactions into Morning, Afternoon, and Evening shifts and calculate the number of orders in each shift.

---

## Key Insights

- Clothing and Beauty categories showed strong customer engagement.
- A small number of customers generated a significant portion of total sales.
- Sales transactions were distributed across Morning, Afternoon, and Evening shifts.
- Monthly sales analysis revealed seasonal purchasing trends.
